1. Средняя сумма чаевых (Big Number):

SELECT round(avg(tip_amount), 2) FROM trips

2. Средняя стоимость по числу пассажиров (Bar Chart):

SELECT
    passenger_count,
    ceil(avg(total_amount), 2) AS average_total_amount
FROM trips
GROUP BY passenger_count

3. Количество поездок по дням (Line Chart):

SELECT
    pickup_date,
    SUM(1) AS number_of_trips
FROM trips
GROUP BY pickup_date
ORDER BY pickup_date ASC

4. Распределение по типу оплаты (Pie Chart):

SELECT
    payment_type,
    count() AS trips_count
FROM trips
GROUP BY payment_type

5. Топ районов по посадкам (Таблица):

SELECT
    pickup_date,
    count() AS number_of_trips
FROM trips
GROUP BY pickup_date
ORDER BY pickup_date ASC
