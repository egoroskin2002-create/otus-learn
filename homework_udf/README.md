1. Создание таблицы transactions
2. Заполнение тестовыми данными
6 строк с транзакциями (покупки пользователей), включая разные цены, количества и даты.

Блок 1: Агрегатные запросы
SUM(quantity * price)
Общая выручка (total_profit) → $759.92
AVG(price * quantity)
Средняя прибыль на транзакцию → $126.65
SUM(quantity)
Всего продано единиц товара → 10
uniq(user_id)
Уникальные пользователи → 4

Блок 2: Работа с датами и преобразованиями
Пример результата
formatDateTime(..., '%Y-%m-%d')
Форматирование даты в строку
'2024-01-15'
toYear(), toMonth(), toYYYYMM()
Извлечение компонентов даты
2024, 1, 202401
round(price)
Округление цены
49.99 → 50
toString(transaction_id)
Преобразование числа в строку
1 → '1'

Блок 3: UDF 
calc_total_price(price, quantity)
Точная сумма: 99.98, 149.99, 89.97, …
calc_total_price_r(...)
Округлённая сумма: 100, 150, 90, …
classify_transaction(...)
Классификация: 'low' / 'high' в зависимости от порога 100
